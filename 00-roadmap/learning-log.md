# Learning Log

> "Learn → Implement → Document → Reflect → Improve"

This file is your engineering journal.

Every completed session should have one entry.

The purpose is **not** to summarize the topic.

The purpose is to improve **how you learn**, **how you think**, and **how you design software**.
