- [ ] Explain every OOP principle.
- [ ] Explain memory model.
- [ ] Explain object relationships.
- [ ] Explain polymorphism with examples.
- [ ] Explain abstraction vs encapsulation.
- [ ] Explain composition vs inheritance.

## LLD

- [ ] Apply SOLID naturally.
- [ ] Select appropriate Design Patterns.
- [ ] Draw UML Class Diagrams.
- [ ] Draw Sequence Diagrams.
- [ ] Explain design decisions.
- [ ] Write clean extensible code.
- [ ] Complete machine coding within interview time.
- [ ] Design systems from scratch confidently.
