# OOPs & Low Level Design (LLD) — Google SDE2 Preparation

A structured self-study repository for mastering **Object-Oriented Programming**, **Design Principles**, **Design Patterns**, and **Low Level Design** from fundamentals to interview-level system design.

The goal of this repository is not just to prepare for coding interviews, but to build the ability to design clean, extensible, maintainable, and production-ready software.

---

## 🎯 Goals

- Master modern Object-Oriented Programming in C++
- Build strong Low Level Design intuition
- Learn when and why to use Design Patterns
- Understand SOLID and software engineering principles
- Practice machine coding and real-world object modeling
- Create reusable notes for quick interview revision
- Build a personal knowledge base accessible from anywhere
